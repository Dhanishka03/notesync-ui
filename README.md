# NoteSync UI

NoteSync UI is a simple, browser-based note-taking app aimed at developers who want to jot things down quickly without leaving the browser. No login, no server — just open the page and start writing.

## Features

- Create new notes with a title and body
- Search through your notes by keyword
- Delete notes you no longer need
- Markdown preview so you can see formatted output as you write
- Cloud sync to keep your notes available across devices
